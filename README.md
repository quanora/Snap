# Snap (BETA)
This is the add-on for Anki, that make process of making cards faster while watching video in foreign language. You don't need to take multiple screenshot and search for data. It will capture from your screen.

The example of card. As for the quality, I think it mostly depends on what model and promt are you using. It's not stable

# How is this work?
Screen → Word Selection → OCR → Context Extraction → LLM → Card Generation → Anki
