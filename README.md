# Snap (BETA)
This is the add-on for Anki, which make process of creating cards faster while watching videos in a foreign language. You don't need to take multiple screenshots and search for information. It will capture from your screen.

The example of a card. The quality mostly depends on what model and promt you are using. The result is not very stable

# How does this work?
Screen → Word Selection → OCR → Context Extraction → LLM → Card Generation → Anki
